# Smart Dukan

Smart Dukan is a digital shop page platform.

## Current V1
- Home/landing page
- Customer registration form
- Local admin dashboard
- Shop profile page
- Call / WhatsApp / Maps / Review
- Product categories
- Basic one-year status tracking
- Node/Express server

## Important
This starter version stores registrations in browser localStorage. It is suitable for a prototype/demo, not for production customer data.

## Run
```bash
npm install
npm start
```
Open http://localhost:3000
